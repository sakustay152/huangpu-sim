## 模拟器（报告"结果分析"的数据来源）

```bat
cd build
huangpu_simulate.exe --simulate 1000 --seed 42 --strategy all --out sim_result.csv
```

- `--strategy trader|worker|mixed|all`，`--seed` 固定可复现（同一套规则类，与游戏共用）。
- 已校准的一组结果（1000 局 × 3 策略，见 `docs/sim_result.csv`）：

| 策略 | 校园合伙人 | 站稳脚跟 | 账单之外 | 平均总资产 | 挂科率 |
| --- | --- | --- | --- | --- | --- |
| mixed（混合） | 0% | **53.7%** | 46.3% | ¥7,720 | 0% |
| trader（只倒卖） | 0% | 0% | 100% | **¥9,282**（最高） | 6.1% |
| worker（只打工） | 0% | 0% | 100% | ¥5,668 | 0% |

> 结论：只倒卖钱最多但没有朋友 → 依旧"账单之外"；只打工最稳但够不到目标；
> **混合策略才是好结局路径，且不存在单一最优解** —— 这正是三线经营的设计目标。

## 玩法（垂直切片已实现）

- **时间**：12 周 × 每周 6 行动点（周一~周六，1 行动点 = 1 天），耗尽自动周日结算。
- **行动**：移动（路费）/ 打工 / 学习 / 社交 / 休息各耗 1 点；**买卖不耗点**。
- **市场**：6 地点 × 12 商品，`mid = base × 地点系数 × 季节 × 周趋势 × 事件冲击 × 日噪声`，
  买卖价差 8%（大件 5%），每地点每日限购，背包 30 格。
- **事件**：4 固定节点（开学/期中/双十一/期末）+ 10 随机事件 + 3 条 NPC 小线，全部 JSON 数据驱动。
- **情报**：室友每周一条，80% 准确（先于行情生成，直接影响下周趋势）。
- **结局**（endings.json 按 priority 判定，条件与事件共用一套 Condition 体系）：
  - 《站稳脚跟》：总资产 ≥ ¥7,500 + 不挂科 + 任一 NPC 好感 ≥ 60
  - 《校园合伙人》（隐藏）：总资产 ≥ ¥8,500 + 学姐 ≥ 80 + 社团 flag
  - 《账单之外》：以上都不满足（不是 Game Over，是带遗憾的开放结局）

REM Output in build\: huangpu_sim.exe / huangpu_simulate.exe / huangpu_tests.exe
REM ============================================================
setlocal

    exit /b 1

    echo [ERROR] vcvars64 init failed
    exit /b 1
)

if not exist build mkdir build
del /q build\*.obj build\*.exe build\*.lib 2>nul

REM ---- response file: src\*.cpp ----
set "RSP=build\sources.rsp"
type nul > %RSP%
for /r src %%f in (*.cpp) do @echo "%%f">>%RSP%

echo [1/3] Compiling rule layer (src/ -> static lib) ...
cl /nologo /std:c++17 /utf-8 /EHsc /W3 /O2 /Iinclude /Ithird_party /c @%RSP%
if errorlevel 1 goto :fail

lib /nologo /out:build\huangpu_core.lib build\*.obj
if errorlevel 1 goto :fail

echo [2/3] Linking game and simulator ...
cl /nologo /std:c++17 /utf-8 /EHsc /W3 /O2 /Iinclude /Ithird_party main\main_console.cpp build\huangpu_core.lib /Fe:build\huangpu_sim.exe

## `CMakeLists.txt`

````text
# ============================================================
# 《黄埔江上又一人》· 校园浮生录 — CMake 构建脚本（组长 A）
# 课程要求：C++17，不使用游戏引擎，仅 C++ 标准库 + 内置 nlohmann/json。
# 本机若无 CMake，用 build.bat（MSVC 直接编译）即可。
# ============================================================
cmake_minimum_required(VERSION 3.15)
project(HuangpuSim LANGUAGES CXX)

set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

include_directories(${CMAKE_CURRENT_SOURCE_DIR}/include)
include_directories(${CMAKE_CURRENT_SOURCE_DIR}/third_party)

# 收集源码
file(GLOB_RECURSE LIB_SOURCES CONFIGURE_DEPENDS ${CMAKE_CURRENT_SOURCE_DIR}/src/*.cpp)
list(FILTER LIB_SOURCES EXCLUDE_REGEX ".*/main/.*")

# 公共库（游戏规则层：core/economy/player/events/story/time/ui/save/simulate）
add_library(huangpu_core STATIC ${LIB_SOURCES})
if (MSVC)
    target_compile_options(huangpu_core PRIVATE /utf-8 /W3 /permissive-)
else()
    target_compile_options(huangpu_core PRIVATE -Wall -Wextra)
endif()

# 目标 1：交互版垂直切片（控制台 demo）
add_executable(huangpu_sim ${CMAKE_CURRENT_SOURCE_DIR}/main/main_console.cpp)
target_link_libraries(huangpu_sim PRIVATE huangpu_core)

# 目标 2：headless 模拟器（报告"结果分析"的数据来源）
add_executable(huangpu_simulate ${CMAKE_CURRENT_SOURCE_DIR}/main/main_simulate.cpp)
target_link_libraries(huangpu_simulate PRIVATE huangpu_core)

# 目标 3：规则测试
add_executable(huangpu_tests ${CMAKE_CURRENT_SOURCE_DIR}/tests/test_main.cpp)
target_link_libraries(huangpu_tests PRIVATE huangpu_core)

# 把 data/ 拷到运行目录，保证任意目录构建后可直接运行
add_custom_command(TARGET huangpu_sim POST_BUILD
    COMMAND ${CMAKE_COMMAND} -E copy_directory
            ${CMAKE_CURRENT_SOURCE_DIR}/data $<TARGET_FILE_DIR:huangpu_sim>/data)
````

#pragma once
// ============================================================
// [core/EventBus] 观察者模式事件总线（组长 A 维护，W1 冻结）
// 分工 7.2：交易完成、周结算、事件触发、结局等通过 EventBus 广播，
// UI（E）订阅刷新，不产生反向依赖。类型安全：按事件类型订阅/发布。
// ============================================================
#include <functional>
#include <typeindex>
#include <unordered_map>
#include <vector>

class EventBus {
public:
    EventBus() = default;
    EventBus(const EventBus&) = delete;
    EventBus& operator=(const EventBus&) = delete;

    template <typename E>
    void subscribe(std::function<void(const E&)> handler) {
        auto eraser = [h = std::move(handler)](const void* p) {
            h(*static_cast<const E*>(p));
        };
        subs_[std::type_index(typeid(E))].push_back(std::move(eraser));
    }

    template <typename E>
    void publish(const E& event) {
        auto it = subs_.find(std::type_index(typeid(E)));
        if (it == subs_.end()) return;
        // 拷贝一份，允许处理器内部再订阅/取消订阅而不破坏迭代
        std::vector<Handler> snapshot = it->second;
        for (const auto& h : snapshot) h(&event);
    }

private:
    using Handler = std::function<void(const void*)>;
    std::unordered_map<std::type_index, std::vector<Handler>> subs_;
};

#pragma once
// ============================================================
// [util/JsonUtil] JSON 读写工具（组长 A 维护）
// - getOr: 带默认值的字段读取（配置/存档缺失字段不崩溃）
// - loadFile: 读取并解析 JSON，失败时抛出带文件名的异常（配置错误是致命错误，
//              游戏运行期逻辑一律用返回值/错误码，不用异常做流程控制）
// ============================================================
#include <string>
#include "util/Json.h"

namespace ju {

// 读取 j[key]，缺失或类型不符时返回 def
template <typename T>
T getOr(const Json& j, const char* key, T def) {
    auto it = j.find(key);
    if (it == j.end() || it->is_null()) return def;
    try {
        return it->get<T>();
    } catch (...) {
        return def;
    }
}

// 从文件加载 JSON；解析失败抛 std::runtime_error（含文件路径与原因）
Json loadFile(const std::string& path);

// 写 JSON 到文件（UTF-8，缩进 2 空格）
void saveFile(const std::string& path, const Json& j);

} // namespace ju

ActionResult WorkCommand::execute(GameContext& ctx) const {
    const auto& jobs = ctx.config.balance().jobs;
    auto it = jobs.find(ctx.locationId);
    int lo = 80, hi = 100;
    std::string jobName = "打零工";
    if (it != jobs.end()) {
        lo = it->second.first;
        hi = it->second.second;
        if (ctx.locationId == "canteen") jobName = "食堂窗口帮工";
        else if (ctx.locationId == "store") jobName = "教育超市理货";
        else if (ctx.locationId == "westgate") jobName = "街头发传单";
    }
    int pay = ctx.rng.range(lo, hi);
    // 学长线回报：好感 ≥30，日薪 +20%（分工 3.5）
    if (ctx.npcs->atLeast("senior", 30)) pay = static_cast<int>(pay * ctx.config.balance().seniorWorkBonus);
    ctx.player->wallet().add(pay);
    return {true, true, jobName + "干了一天，工资 +¥" + std::to_string(pay)};
}

void ConfigManager::loadGoods() {
    Json j = ju::loadFile(pathOf("goods.json"));
    if (!j.is_array()) fail("goods.json 顶层必须是数组");
    for (const auto& e : j) {
        GoodsDef g;
        g.id         = ju::getOr<std::string>(e, "id", "");
        g.name       = ju::getOr<std::string>(e, "name", g.id);
        g.category   = ju::getOr<std::string>(e, "category", "");
        g.basePrice  = ju::getOr(e, "basePrice", 1);
        g.spread     = ju::getOr(e, "spread", 0.08);
        g.slots      = ju::getOr(e, "slots", 1);
        g.limitPerDay = ju::getOr(e, "limitPerDay", 15);
        g.desc       = ju::getOr<std::string>(e, "desc", "");
        if (g.id.empty()) fail("goods.json 存在缺少 id 的商品");
        if (e.contains("soldAt") && e["soldAt"].is_array())
            for (const auto& s : e["soldAt"]) g.soldAt.push_back(s.get<std::string>());
        if (e.contains("locFactor") && e["locFactor"].is_object())
            for (auto it = e["locFactor"].begin(); it != e["locFactor"].end(); ++it)
                g.locFactor[it.key()] = it.value().get<double>();
        if (e.contains("peakWeeks") && e["peakWeeks"].is_array())
            for (const auto& w : e["peakWeeks"]) g.peakWeeks.push_back(w.get<int>());
        goods_.push_back(std::move(g));
    }
    if (goods_.empty()) fail("goods.json 没有任何商品");
}

void Game::performAction(std::unique_ptr<ICommand> cmd) {

    ActionOutcome out = Session::runAction(*c, *cmd);
    c->lastFeedback = out.result.msg;

    if (out.result.ok && out.result.consumedAp && c->time->actionsLeft() == 0 &&
        !c->time->isSemesterOver()) {
        requestEndWeek();
    }

void Game::requestEndWeek() {
    GameContext* c = ctx_.get();
    if (!c || endingPending_ || c->time->isSemesterOver()) return;

    WeekSettlement settle(*c);
    lastReport_ = settle.run();

    // 每周日自动存档（分工 7.2）
    std::string err;
    saveGame(SaveManager::kAutoSlot, err);

    queueWeeklyReport(); // 周报最先弹出
    if (c->time->isSemesterOver()) {
        chosenEnding_ = EndingJudge::judge(*c);
        bus().publish(EndingDecidedEvent{chosenEnding_->id, chosenEnding_->title});
        endingPending_ = true;
        screens_.popAll(); // 校园退役，周报关闭后直接进结局
    } else {
        // 新一周的固定节点（期中/双十一/期末…）依序入队
        for (const GameEvent* ev : c->events->fixedForWeek(c->time->week(), *c))
            queueEventDialog(ev);
    }
}

std::uint64_t Random::next() {
    std::uint64_t z = (state_ += 0x9E3779B97F4A7C15ull);
    z = (z ^ (z >> 30)) * 0xBF58476D1CE4E5B9ull;
    z = (z ^ (z >> 27)) * 0x94D049BB133111EBull;
    return z ^ (z >> 31);
}

int Random::range(int lo, int hi) {
    if (hi <= lo) return lo;
    return lo + static_cast<int>(next() % static_cast<std::uint64_t>(hi - lo + 1));
}

double Random::real() {
    return static_cast<double>(next() >> 11) * (1.0 / 9007199254740992.0);
}

bool Random::chance(double p) {
    if (p >= 1.0) return true;
    if (p <= 0.0) return false;
    return real() < p;
}

double Random::uniform(double lo, double hi) {
    return lo + real() * (hi - lo);
}

Json Random::toJson() const {
    return Json{{"state", state_}};
}

void Random::fromJson(const Json& j) {
    state_ = ju::getOr(j, "state", state_);

ActionOutcome Session::runAction(GameContext& ctx, const ICommand& cmd) {
    ActionOutcome out;
    if (!ctx.time->canAct()) {
        out.result = {false, false, "本周行动点已用完（周日晚自动结算）"};
        return out;
    }
    ActionResult r = cmd.execute(ctx);
    out.result = r;
    if (!(r.ok && r.consumedAp)) return out;

    // 时间推进：一个行动点 = 一天
    ctx.time->spendAction();
    // 通过 ITimeListener 接口通知行情（面向接口，不面向实现）
    ITimeListener& marketListener = *ctx.market;
    marketListener.onDayTick();
    ctx.bus.publish(ActionTakenEvent{cmd.name()});

    // 概率摇随机事件（数据驱动，分工 8.2）
    if (ctx.rng.chance(ctx.config.balance().eventChance)) {
        if (const GameEvent* ev = ctx.events->rollRandom(ctx)) out.event = ev;
    }
    return out;
}

std::string Session::applyChoice(GameContext& ctx, const GameEvent& ev, int choiceIdx) {
    if (ev.choices.empty()) return "";
    if (choiceIdx < 0 || choiceIdx >= static_cast<int>(ev.choices.size())) choiceIdx = 0;
    const auto& choice = ev.choices[static_cast<std::size_t>(choiceIdx)];

    std::string out = "你选择了：" + choice.text;
    for (const auto& effect : choice.effects) {
        std::string msg = effect->apply(ctx);
        if (!msg.empty()) out += "\n  · " + msg;
    }
    ctx.flags->set("evt_done_" + ev.id); // 一次性事件标记（GameEvent::canTrigger 读取）
    ctx.events->markTriggered(ev);       // 随机事件冷却登记
    return out;
}

Market::Market(const ConfigManager& cfg, Random& rng)
    : cfg_(cfg), rng_(rng), chain_(buildDefaultPriceChain(cfg.balance())) {}

Market::~Market() = default;

double Market::trendOf(const std::string& locId, const std::string& goodsId) const {
    auto it = trend_.find(locId);
    if (it == trend_.end()) return 0.0;
    auto it2 = it->second.find(goodsId);
    return it2 == it->second.end() ? 0.0 : it2->second;
}

double Market::noiseOf(const std::string& goodsId) const {
    auto it = noiseMult_.find(goodsId);
    return it == noiseMult_.end() ? 1.0 : it->second;
}

double Market::shockOf(const std::string& goodsId) const {
    auto it = shock_.find(goodsId);
    return it == shock_.end() ? 1.0 : it->second.first;
}

double Market::midPrice(const std::string& locId, const std::string& goodsId) const {
    const GoodsDef* g = cfg_.goods(goodsId);
    const LocationDef* l = cfg_.location(locId);
    if (!g || !l) return 1.0;
    PriceContext c{*g, *l, week_, trendOf(locId, goodsId), noiseOf(goodsId), shockOf(goodsId)};
    return chain_->price(c);
}

int Market::buyPrice(const std::string& locId, const std::string& goodsId) const {
    const GoodsDef* g = cfg_.goods(goodsId);
    if (!g) return 1;
    double mid = midPrice(locId, goodsId);
    return std::max(1, static_cast<int>(std::round(mid * (1.0 + g->spread))));
}

int Market::sellPrice(const std::string& locId, const std::string& goodsId) const {
    const GoodsDef* g = cfg_.goods(goodsId);
    if (!g) return 1;
    double mid = midPrice(locId, goodsId);
    return std::max(1, static_cast<int>(std::round(mid * (1.0 - g->spread))));
}

std::vector<Market::Listing> Market::listAt(const std::string& locId) const {
    std::vector<Listing> out;
    out.reserve(cfg_.goods().size());
    for (const auto& g : cfg_.goods()) {
        Listing li;
        li.goods = &g;
        li.buyPrice = buyPrice(locId, g.id);
        li.sellPrice = sellPrice(locId, g.id);
        li.canBuy = std::find(g.soldAt.begin(), g.soldAt.end(), locId) != g.soldAt.end();
        li.quotaLeft = quotaLeft(locId, g.id);
        out.push_back(li);
    }
    return out;
}

int Market::quotaLeft(const std::string& locId, const std::string& goodsId) const {
    auto it = quota_.find(locId);
    if (it == quota_.end()) {
        const GoodsDef* g = cfg_.goods(goodsId);
        return g ? g->limitPerDay : 0;
    }
    auto it2 = it->second.find(goodsId);
    if (it2 != it->second.end()) return it2->second;
    const GoodsDef* g = cfg_.goods(goodsId);
    return g ? g->limitPerDay : 0;
}

bool Market::consumeQuota(const std::string& locId, const std::string& goodsId, int qty) {
    if (quotaLeft(locId, goodsId) < qty) return false;
    quota_[locId][goodsId] -= qty;
    return true;
}

void Market::applyShock(const std::string& goodsId, double mult, int days) {
    if (!cfg_.goods(goodsId)) return;
    if (mult <= 0.0) mult = 1.0;
    if (days <= 0) days = 1;
    shock_[goodsId] = {mult, days};
}

void Market::onDayTick() {
    double amp = cfg_.balance().noiseAmp;
    for (const auto& g : cfg_.goods())
        noiseMult_[g.id] = 1.0 + rng_.uniform(-amp, amp);
    // 冲击衰减：按"行动点/天"倒数
    for (auto it = shock_.begin(); it != shock_.end();) {
        if (--it->second.second <= 0) it = shock_.erase(it);
        else ++it;
    }
    resetQuotas(); // 限购按"次到访/天"刷新（分工 3.4：每地点每日 10-20 件）
}

void Market::resetQuotas() {
    quota_.clear();
    for (const auto& g : cfg_.goods())
        for (const auto& loc : g.soldAt)
            quota_[loc][g.id] = g.limitPerDay;
}

void Market::onWeekStart() {
    double amp = cfg_.balance().trendAmp;
    // 全部 (loc, goods) 摇新趋势；情报命中的商品按情报方向偏移
    for (const auto& l : cfg_.locations()) {
        for (const auto& g : cfg_.goods()) {
            double t = rng_.uniform(-amp, amp);
            if (hasRumor_ && pendingRumor_.goodsId == g.id) {
                bool hit = rng_.chance(cfg_.balance().rumorAccuracy);
                double strength = rng_.uniform(0.4, 1.0) * amp;
                t = hit ? (pendingRumor_.up ? strength : -strength)
                        : rng_.uniform(-amp, amp);
            }
            trend_[l.id][g.id] = t;
        }
    }
    hasRumor_ = false;
    onDayTick(); // 新一周的第一天：噪声 + 限购
}

void Market::rollRumor() {
    const auto& goods = cfg_.goods();
    const GoodsDef* g = &goods[rng_.next() % goods.size()];
    bool up = rng_.chance(0.5);
    pendingRumor_ = {g->id, up};
    hasRumor_ = true;
    rumorTexts_.clear();
    rumorTexts_.push_back(std::string("【室友情报】听说下周「") + g->name + "」的价格可能要" +
                          (up ? "涨" : "跌") + "，准确率约 " +
                          std::to_string(static_cast<int>(cfg_.balance().rumorAccuracy * 100)) + "%");
}

const char* Market::trendArrow(const std::string& locId, const std::string& goodsId) const {
    double t = trendOf(locId, goodsId);
    if (t > 0.06) return "▲";
    if (t < -0.06) return "▼";
    return "─";
}

Json Market::toJson() const {
    Json trends = Json::object();
    for (const auto& [loc, gm] : trend_) {
        Json o = Json::object();
        for (const auto& [g, t] : gm) o[g] = t;
        trends[loc] = o;
    }
    Json noise = Json::object();
    for (const auto& [g, m] : noiseMult_) noise[g] = m;
    Json shocks = Json::array();
    for (const auto& [g, sd] : shock_)
        shocks.push_back(Json{{"goods", g}, {"mult", sd.first}, {"days", sd.second}});
    Json quotas = Json::object();
    for (const auto& [loc, gm] : quota_) {
        Json o = Json::object();
        for (const auto& [g, q] : gm) o[g] = q;
        quotas[loc] = o;
    }
    Json rumor;
    if (hasRumor_) rumor = Json{{"goods", pendingRumor_.goodsId}, {"up", pendingRumor_.up}};
    return Json{
        {"week", week_},
        {"trend", trends},
        {"noise", noise},
        {"shock", shocks},
        {"quota", quotas},
        {"pendingRumor", rumor},
        {"rumorTexts", rumorTexts_},
    };
}

void Market::fromJson(const Json& j) {
    week_ = ju::getOr(j, "week", week_);
    trend_.clear();
    if (j.contains("trend") && j["trend"].is_object())
        for (auto it = j["trend"].begin(); it != j["trend"].end(); ++it)
            for (auto it2 = it.value().begin(); it2 != it.value().end(); ++it2)
                trend_[it.key()][it2.key()] = it2.value().get<double>();
    noiseMult_.clear();
    if (j.contains("noise") && j["noise"].is_object())
        for (auto it = j["noise"].begin(); it != j["noise"].end(); ++it)
            noiseMult_[it.key()] = it.value().get<double>();
    shock_.clear();
    if (j.contains("shock") && j["shock"].is_array())
        for (const auto& e : j["shock"]) {
            std::string g = ju::getOr<std::string>(e, "goods", "");
            if (!cfg_.goods(g)) continue;
            shock_[g] = {ju::getOr(e, "mult", 1.0), ju::getOr(e, "days", 1)};
        }
    quota_.clear();
    if (j.contains("quota") && j["quota"].is_object())
        for (auto it = j["quota"].begin(); it != j["quota"].end(); ++it)
            for (auto it2 = it.value().begin(); it2 != it.value().end(); ++it2)
                quota_[it.key()][it2.key()] = it2.value().get<int>();
    hasRumor_ = false;
    if (j.contains("pendingRumor") && j["pendingRumor"].is_object()) {
        std::string g = ju::getOr<std::string>(j["pendingRumor"], "goods", "");
        if (cfg_.goods(g)) {
            pendingRumor_ = {g, ju::getOr(j["pendingRumor"], "up", true)};
            hasRumor_ = true;
        }
    }
    rumorTexts_.clear();
    if (j.contains("rumorTexts") && j["rumorTexts"].is_array())
        for (const auto& t : j["rumorTexts"]) rumorTexts_.push_back(t.get<std::string>());
}

                break;
            }
        }
        if (all) return e;
    }
    throw std::runtime_error("endings.json 缺少兜底结局（priority=99, always）");

const GameEvent* EventScheduler::rollRandom(const GameContext& ctx) {
    // 候选：随机事件 + 条件通过 + 冷却结束
    std::vector<const RandomEvent*> candidates;
    std::vector<int> weights;
    for (const auto& ev : all_) {
        auto* r = dynamic_cast<const RandomEvent*>(ev.get());
        if (!r) continue;
        auto it = cooldown_.find(r->id);
        if (it != cooldown_.end() && it->second > 0) continue;
        if (!r->canTrigger(ctx)) continue;
        candidates.push_back(r);
        weights.push_back(std::max(1, r->weight(ctx)));
    }
    if (candidates.empty()) return nullptr;
    int total = 0;
    for (int w : weights) total += w;
    int roll = rng_.range(1, total);
    for (std::size_t i = 0; i < candidates.size(); ++i) {
        roll -= weights[i];
        if (roll <= 0) return candidates[i];
    }
    return candidates.back();
}

void EventScheduler::markTriggered(const GameEvent& ev) {
    auto* r = dynamic_cast<const RandomEvent*>(&ev);
    if (r && r->cooldownWeeks > 0) cooldown_[r->id] = r->cooldownWeeks + 1; // 本周结算时递减一次
}

void EventScheduler::scheduleEffect(int dueWeek, Json effectJson) {

void EventScheduler::applyDueEffects(GameContext& ctx) {
    int now = ctx.time->week();
    for (auto it = scheduled_.begin(); it != scheduled_.end();) {
        if (it->first <= now) {
            auto eff = EffectFactory::create(it->second);
            eff->apply(ctx);
            it = scheduled_.erase(it);
        } else {
            ++it;
        }
    }
}

void EventScheduler::onWeekStart() {
    for (auto it = cooldown_.begin(); it != cooldown_.end();) {
        if (--it->second <= 0) it = cooldown_.erase(it);
        else ++it;
    }
}

    for (const auto& c : conditions)
        if (!c->test(ctx)) return false;
    return true;
}

void GameEvent::apply(GameContext& ctx) const {
    if (choices.empty()) return;
    for (const auto& e : choices.front().effects) e->apply(ctx);
    ctx.flags->set("evt_done_" + id);
}

bool FixedEvent::canTrigger(const GameContext& ctx) const {
    if (ctx.time->week() != week) return false;
    return GameEvent::canTrigger(ctx);
}

bool NpcEvent::canTrigger(const GameContext& ctx) const {

    return GameEvent::canTrigger(ctx);

void Inventory::add(const std::string& goodsId, int qty, double unitCost, int slotsPer) {
    if (qty <= 0) return;
    Item* it = findMutable(goodsId);
    if (it) {
        double totalCost = it->avgCost * it->qty + unitCost * qty;
        it->qty += qty;
        it->avgCost = totalCost / it->qty;
    } else {
        items_.push_back({goodsId, qty, slotsPer, unitCost});
    }
}

bool Inventory::remove(const std::string& goodsId, int qty) {
    Item* it = findMutable(goodsId);
    if (!it || it->qty < qty) return false;
    it->qty -= qty;
    if (it->qty == 0) {
        // 保持顺序，移除空堆叠
        for (std::size_t i = 0; i < items_.size(); ++i) {
            if (items_[i].goodsId == goodsId) {
                items_.erase(items_.begin() + static_cast<long>(i));
                break;
            }
        }
    }
    return true;
}

            {"qty", it.qty},

}

    }

TradeResult TradeSystem::buy(GameContext& ctx, const std::string& goodsId, int qty) const {
    const GoodsDef* g = cfg_.goods(goodsId);
    if (!g) return {false, "没有这种商品: " + goodsId};
    if (qty <= 0) return {false, "数量必须为正"};

    // 地点校验：这里有没有卖
    const LocationDef* loc = cfg_.location(ctx.locationId);
    bool soldHere = std::find(g->soldAt.begin(), g->soldAt.end(), ctx.locationId) != g->soldAt.end();
    if (!soldHere) return {false, std::string("「") + g->name + "」在" + (loc ? loc->name : ctx.locationId) + "没有卖"};

    // 限购校验（每地点每日，1 行动点=1 天，分工 3.4）
    int quota = ctx.market->quotaLeft(ctx.locationId, goodsId);
    if (quota <= 0) return {false, std::string("「") + g->name + "」今天在这里的限购额度已用完，明天再来"};
    int realQty = std::min(qty, quota);

    // 单价（社交线折扣：学长资料 9 折）
    int unit = ctx.market->buyPrice(ctx.locationId, goodsId);
    if (goodsId == "kaoyan_notes" && ctx.flags->has("senior_notes"))
        unit = std::max(1, static_cast<int>(unit * cfg_.balance().kaoyanDiscount));

    // 容量校验（背包是硬约束）
    if (!ctx.player->inventory().canFit(realQty, g->slots)) {
        int fit = ctx.player->inventory().freeSlots() / g->slots;
        realQty = std::min(realQty, fit);
        if (realQty <= 0) return {false, "背包塞不下了，先卖点东西吧"};
    }

    int total = unit * realQty;
    if (!ctx.player->wallet().canAfford(total)) {
        int afford = unit > 0 ? static_cast<int>(ctx.player->wallet().get() / unit) : 0;
        realQty = std::min(realQty, afford);
        if (realQty <= 0) return {false, "现金不够，先打工或者卖货吧"};
        total = unit * realQty;
    }

    // 全部通过：落地（钱包/背包/限购/事件总线）
    ctx.player->wallet().spend(total);
    ctx.player->inventory().add(goodsId, realQty, static_cast<double>(unit), g->slots);
    ctx.market->consumeQuota(ctx.locationId, goodsId, realQty);
    ctx.bus.publish(TradeCompletedEvent{goodsId, realQty, total, true});

    return {true, "买入「" + g->name + "」x" + std::to_string(realQty) + "，支出 ¥" + std::to_string(total), total};
}

TradeResult TradeSystem::sell(GameContext& ctx, const std::string& goodsId, int qty) const {
    const GoodsDef* g = cfg_.goods(goodsId);
    if (!g) return {false, "没有这种商品: " + goodsId};
    if (qty <= 0) return {false, "数量必须为正"};

    const Inventory::Item* item = ctx.player->inventory().find(goodsId);
    if (!item) return {false, std::string("背包里没有「") + g->name + "」"};
    int realQty = std::min(qty, item->qty);

    int unit = ctx.market->sellPrice(ctx.locationId, goodsId);
    // 社交线加成：学姐内部票（演出门票卖出 +25%）
    if (goodsId == "show_ticket" && ctx.flags->has("inner_ticket"))
        unit = std::max(1, static_cast<int>(unit * cfg_.balance().innerTicketBonus));

    int total = unit * realQty;
    double costBasis = item->avgCost * realQty;
    ctx.player->wallet().add(total);
    ctx.player->inventory().remove(goodsId, realQty);
    ctx.bus.publish(TradeCompletedEvent{goodsId, realQty, total, false});

    long long profit = static_cast<long long>(total) - static_cast<long long>(costBasis);
    std::string msg = "卖出「" + g->name + "」x" + std::to_string(realQty) + "，收入 ¥" + std::to_string(total);
    if (profit >= 0) msg += "（盈利 ¥" + std::to_string(profit) + "）";
    else msg += "（亏损 ¥" + std::to_string(-profit) + "）";
    return {true, msg, total};
}

int TradeSystem::estimatePortfolioValue(const GameContext& ctx) const {
    int value = 0;
    for (const auto& item : ctx.player->inventory().items()) {
        int best = 0;
        for (const auto& loc : cfg_.locations()) {
            int p = ctx.market->sellPrice(loc.id, item.goodsId);
            if (p > best) best = p;
        }
        value += best * item.qty;
    }
    return value;
}

// 简单解析器：选"估算现金收益最大"的选项（IEffect::estimateMoneyDelta 多态求和）
class SimResolver : public IChoiceResolver {
public:
    int chooseChoice(const GameEvent& ev, const GameContext& ctx) const override {
        (void)ctx;
        int best = 0;
        long long bestValue = std::numeric_limits<long long>::min();
        for (std::size_t i = 0; i < ev.choices.size(); ++i) {
            long long v = 0;
            for (const auto& e : ev.choices[i].effects) v += e->estimateMoneyDelta();
            if (v > bestValue) {
                bestValue = v;
                best = static_cast<int>(i);
            }
        }
        return best;
    }
};

// 执行一条消耗行动点的命令；途中触发的随机事件由 resolver 立即解决
bool runApCommand(GameContext& ctx, const ICommand& cmd, const IChoiceResolver& resolver) {
    ActionOutcome out = Session::runAction(ctx, cmd);
    if (out.event) Session::applyChoice(ctx, *out.event, resolver.chooseChoice(*out.event, ctx));
    return out.result.ok && out.result.consumedAp;
}

// 某商品在各地的最高卖价（及地点 id）
std::pair<int, std::string> bestSell(GameContext& ctx, const std::string& goodsId) {
    int best = 0;
    std::string bestLoc;
    for (const auto& l : ctx.config.locations()) {
        int p = ctx.market->sellPrice(l.id, goodsId);
        if (p > best) {
            best = p;
            bestLoc = l.id;
        }
    }
    return {best, bestLoc};
}

// ---------------- 只倒卖：低买高卖，周内周转 ----------------
class TraderBot : public BotStrategy {
public:
    std::string name() const override { return "trader"; }
    bool takeTurn(GameContext& ctx) override {
        if (!ctx.time->canAct()) return false;

        // 学业底线：期中前把分数拉到 58 以上
        if (ctx.time->week() >= 5 && ctx.player->studyScore() < 58) {
            if (ctx.locationId != "library") return runApCommand(ctx, MoveCommand("library"), resolver_);
            return runApCommand(ctx, StudyCommand(), resolver_);
        }
        // 1) 有库存 → 去最优地点卖
        const auto& items = ctx.player->inventory().items();
        if (!items.empty()) {
            const Inventory::Item* bestItem = nullptr;
            int bestProfit = -1;
            std::string bestLoc;
            for (const auto& it : items) {
                auto [p, loc] = bestSell(ctx, it.goodsId);
                int profit = (p - static_cast<int>(it.avgCost)) * it.qty;
                if (profit > bestProfit) {
                    bestProfit = profit;
                    bestItem = &it;
                    bestLoc = loc;
                }
            }
            if (bestItem && bestProfit > 0) {
                if (ctx.locationId == bestLoc) {
                    // 就地清仓所有"此地即最优"的货（免行动点）
                    for (const auto& it : items) {
                        if (bestSell(ctx, it.goodsId).second != ctx.locationId) continue;
                        const Inventory::Item* cur = ctx.player->inventory().find(it.goodsId);
                        if (cur) ctx.trade->sell(ctx, it.goodsId, cur->qty);
                    }
                    return false;
                }
                return runApCommand(ctx, MoveCommand(bestLoc), resolver_);
            }
        }

        // 2) 扫描进货机会：毛利/占格 最大者
        int bestMargin = -1;
        std::string bestGoods, bestBuyLoc;
        for (const auto& g : ctx.config.goods()) {
            if (!ctx.player->inventory().canFit(1, g.slots)) continue;
            auto [sellP, sellLoc] = bestSell(ctx, g.id);
            for (const auto& buyLocId : g.soldAt) {
                int buyP = ctx.market->buyPrice(buyLocId, g.id);
                if (ctx.market->quotaLeft(buyLocId, g.id) <= 0) continue;
                int margin = sellP - buyP;
                if (margin <= 0) continue;
                int marginPerSlot = margin / g.slots;
                if (marginPerSlot > bestMargin) {
                    bestMargin = marginPerSlot;
                    bestGoods = g.id;
                    bestBuyLoc = buyLocId;
                }
            }
        }
        const GoodsDef* bg = bestGoods.empty() ? nullptr : ctx.config.goods(bestGoods);
        if (bg) {
            int buyP = ctx.market->buyPrice(bestBuyLoc, bestGoods);
            auto [sellP, sellLoc] = bestSell(ctx, bestGoods);
            double ratio = buyP > 0 ? static_cast<double>(sellP - buyP) / buyP : 0.0;
            if (ratio > 0.12 && sellLoc != bestBuyLoc) { // 12% 毛利才出手，防止无意义倒手
                if (ctx.locationId == bestBuyLoc) {
                    int affordable = buyP > 0 ? ctx.player->wallet().get() / buyP : 0;
                    int fit = ctx.player->inventory().freeSlots() / bg->slots;
                    int qty = std::min({ctx.market->quotaLeft(bestBuyLoc, bestGoods), affordable, fit});
                    if (qty > 0) {
                        ctx.trade->buy(ctx, bestGoods, qty);
                        return false;
                    }
                }
                return runApCommand(ctx, MoveCommand(bestBuyLoc), resolver_);
            }
        }

        // 3) 兜底：打工
        return runApCommand(ctx, WorkCommand(), resolver_);
    }

private:
    SimResolver resolver_;
};

// ---------------- 混合：打工攒本 + 高毛利倒卖 + 兼顾学业 ----------------
class MixedBot : public BotStrategy {
public:
    std::string name() const override { return "mixed"; }
    bool takeTurn(GameContext& ctx) override {
        if (!ctx.time->canAct()) return false;

        // 学业：稳在及格线上方（不冲奖学金——行动点拿去经营更划算）
        if (ctx.player->studyScore() < 70 ||
            (ctx.time->week() >= 6 && !ctx.time->studiedThisWeek() && ctx.player->studyScore() < 74)) {
            if (ctx.locationId != "library") return runApCommand(ctx, MoveCommand("library"), resolver_);
            return runApCommand(ctx, StudyCommand(), resolver_);
        }

        // 清仓（同 TraderBot）
        const auto& items = ctx.player->inventory().items();
        if (!items.empty()) {
            std::string bestLoc;
            int bestProfit = -1;
            for (const auto& it : items) {
                auto [p, loc] = bestSell(ctx, it.goodsId);
                int profit = (p - static_cast<int>(it.avgCost)) * it.qty;
                if (profit > bestProfit) {
                    bestProfit = profit;
                    bestLoc = loc;
                }
            }
            if (bestProfit > 0) {
                if (ctx.locationId == bestLoc) {
                    for (const auto& it : items) {
                        if (bestSell(ctx, it.goodsId).second != ctx.locationId) continue;
                        const Inventory::Item* cur = ctx.player->inventory().find(it.goodsId);
                        if (cur) ctx.trade->sell(ctx, it.goodsId, cur->qty);
                    }
                    return false;
                }
                return runApCommand(ctx, MoveCommand(bestLoc), resolver_);
            }
        }

        // 社交底线：好结局需要一位好友（好感 ≥60），空闲时维护到 80
        bool urgentSocial = ctx.npcs->maxAffinity() < 60;
        bool casualSocial = ctx.npcs->maxAffinity() < 80;
        if (urgentSocial || casualSocial) {
            const LocationDef* loc = ctx.config.location(ctx.locationId);
            bool npcHere = loc && !loc->npcId.empty();
            if (npcHere && (urgentSocial || !hasGoodBuyOpportunity(ctx)))
                return runApCommand(ctx, SocialCommand(), resolver_);
            if (urgentSocial) return runApCommand(ctx, MoveCommand("dorm"), resolver_);
        }

        // 本金少先打工攒本
        if (ctx.player->wallet().get() < 1200) return runApCommand(ctx, WorkCommand(), resolver_);

        // 高毛利才进货（13% 门槛，比纯倒卖略保守）
        int bestMargin = -1;
        std::string bestGoods, bestBuyLoc;
        for (const auto& g : ctx.config.goods()) {
            if (!ctx.player->inventory().canFit(1, g.slots)) continue;
            auto [sellP, sellLoc] = bestSell(ctx, g.id);
            if (sellLoc.empty() || sellLoc == "?") continue;
            for (const auto& buyLocId : g.soldAt) {
                if (buyLocId == sellLoc) continue; // 混合策略不原地倒手
                int buyP = ctx.market->buyPrice(buyLocId, g.id);
                if (ctx.market->quotaLeft(buyLocId, g.id) <= 0) continue;
                int marginPerSlot = (sellP - buyP) / g.slots;
                if (marginPerSlot > bestMargin) {
                    bestMargin = marginPerSlot;
                    bestGoods = g.id;
                    bestBuyLoc = buyLocId;
                }
            }
        }
        const GoodsDef* bg = bestGoods.empty() ? nullptr : ctx.config.goods(bestGoods);
        if (bg) {
            int buyP = ctx.market->buyPrice(bestBuyLoc, bestGoods);
            auto [sellP, sellLoc] = bestSell(ctx, bestGoods);
            double ratio = buyP > 0 ? static_cast<double>(sellP - buyP) / buyP : 0.0;
            if (ratio > 0.13) {
                if (ctx.locationId == bestBuyLoc) {
                    int affordable = buyP > 0 ? ctx.player->wallet().get() / buyP : 0;
                    int fit = ctx.player->inventory().freeSlots() / bg->slots;
                    int qty = std::min({ctx.market->quotaLeft(bestBuyLoc, bestGoods), affordable, fit});
                    if (qty > 0) {
                        ctx.trade->buy(ctx, bestGoods, qty);
                        return false;
                    }
                }
                return runApCommand(ctx, MoveCommand(bestBuyLoc), resolver_);
            }
        }
        return runApCommand(ctx, WorkCommand(), resolver_);
    }

private:
    SimResolver resolver_;

    // 是否存在值得出手的进货机会（毛利 ≥13%）
    bool hasGoodBuyOpportunity(GameContext& ctx) const {
        for (const auto& g : ctx.config.goods()) {
            if (!ctx.player->inventory().canFit(1, g.slots)) continue;
            auto [sellP, sellLoc] = bestSell(ctx, g.id);
            if (sellLoc.empty()) continue;
            for (const auto& buyLocId : g.soldAt) {
                if (buyLocId == sellLoc) continue;
                int buyP = ctx.market->buyPrice(buyLocId, g.id);
                if (buyP > 0 && ctx.market->quotaLeft(buyLocId, g.id) > 0 &&
                    static_cast<double>(sellP - buyP) / buyP > 0.13)
                    return true;
            }
        }
        return false;
    }
};

} // namespace

const IChoiceResolver& defaultResolver() {
    static SimResolver r;
    return r;
}

std::unique_ptr<BotStrategy> makeStrategy(const std::string& name) {
    if (name == "trader") return std::make_unique<TraderBot>();
    if (name == "worker") return std::make_unique<WorkerBot>();
    if (name == "mixed") return std::make_unique<MixedBot>();
    throw std::runtime_error("未知策略: " + name + "（可选 trader/worker/mixed）");
}

SimGameResult SimulationRunner::runOne(const std::string& strategyName, std::uint64_t seed) {
    Random rng(seed);
    EventBus bus;
    GameContext ctx(cfg_, rng, bus);
    ctx.initNewGame();

    auto bot = makeStrategy(strategyName);

    // 第 1 周固定节点立即解决（Bot 选"对自己最有利"的选项）
    for (const GameEvent* ev : ctx.events->fixedForWeek(1, ctx)) {
        Session::applyChoice(ctx, *ev, defaultResolver().chooseChoice(*ev, ctx));
    }

    int guard = 0;
    int stall = 0;
    int minMoney = ctx.player->wallet().get();
    while (!ctx.time->isSemesterOver() && guard++ < 20000) {
        bool consumed = bot->takeTurn(ctx);
        stall = consumed ? 0 : stall + 1;
        if (stall > 8) { // 兜底：策略卡住则强制进入周日结算
            ctx.time->forceEndWeek();
            stall = 0;
        }
        minMoney = std::min(minMoney, ctx.player->wallet().get());
        if (!ctx.time->canAct()) {
            WeekSettlement settle(ctx);
            settle.run();
            if (!ctx.time->isSemesterOver()) {
                for (const GameEvent* ev : ctx.events->fixedForWeek(ctx.time->week(), ctx)) {
                    Session::applyChoice(ctx, *ev, defaultResolver().chooseChoice(*ev, ctx));
                }
            }
        }
    }

    SimGameResult r;
    r.seed = seed;
    r.strategy = strategyName;
    const EndingDef* ending = EndingJudge::judge(ctx);
    r.endingId = ending ? ending->id : "?";
    r.finalCash = ctx.player->wallet().get();
    r.portfolioValue = ctx.trade->estimatePortfolioValue(ctx);
    r.studyScore = ctx.player->studyScore();
    r.maxAffinity = ctx.npcs->maxAffinity();
    r.failed = ctx.flags->has("failed");
    r.minMoney = minMoney;
    return r;
}

std::vector<SimGameResult> SimulationRunner::runGames(const std::string& strategyName,
                                                      std::uint64_t seed0, int count) {
    std::vector<SimGameResult> out;
    out.reserve(static_cast<std::size_t>(count));
    for (int i = 0; i < count; ++i) {
        out.push_back(runOne(strategyName, seed0 + static_cast<std::uint64_t>(i)));
    }
    return out;
}

void SimulationRunner::printSummary(const std::vector<SimGameResult>& results) {
    // 按策略聚合
    std::map<std::string, std::vector<const SimGameResult*>> byStrategy;
    for (const auto& r : results) byStrategy[r.strategy].push_back(&r);

    std::cout << "\n==== 1000 局模拟摘要（同一套规则，无 UI）====\n";
    std::cout << "策略      局数  校园合伙人  站稳脚跟  账单之外  平均总资产   中位总资产   挂科率  平均平时分  最低现金均值\n";
    for (auto& [name, rs] : byStrategy) {
        std::map<std::string, int> endings;
        long long totalSum = 0;
        std::vector<int> totals;
        int failed = 0;
        long long studySum = 0;
        long long minMoneySum = 0;
        for (const auto* r : rs) {
            endings[r->endingId]++;
            int total = r->finalCash + r->portfolioValue;
            totalSum += total;
            totals.push_back(total);
            studySum += r->studyScore;
            minMoneySum += r->minMoney;
            if (r->failed) ++failed;
        }
        std::sort(totals.begin(), totals.end());
        int median = totals.empty() ? 0 : totals[totals.size() / 2];
        auto rate = [&](const char* id) {
            auto it = endings.find(id);
            double v = it == endings.end() ? 0.0 : static_cast<double>(it->second) / rs.size();
            char buf[16];
            std::snprintf(buf, sizeof(buf), "%.1f%%", v * 100);
            return std::string(buf);
        };
        char line[256];
        std::snprintf(line, sizeof(line), "%-9s %-5d %-10s %-9s %-9s %-11lld %-12d %-7s %-11lld %lld",
                      name.c_str(), static_cast<int>(rs.size()), rate("partner").c_str(), rate("steady").c_str(),
                      rate("beyond").c_str(), totalSum / static_cast<long long>(rs.size()), median,
                      ([&] { char b[16]; std::snprintf(b, sizeof(b), "%.1f%%",
                              static_cast<double>(failed) / rs.size() * 100); return std::string(b); })().c_str(),
                      studySum / static_cast<long long>(rs.size()),
                      minMoneySum / static_cast<long long>(rs.size()));
        std::cout << line << "\n";
    }
}

    }

void MarketScreen::handleInput(const std::string& in) {
    GameContext* c = game_.ctx();
    if (!c) return;
    std::string cmd = strutil::toLower(in);
    if (cmd == "q" || cmd.empty()) {
        game_.screens().pop();
        return;
    }
    auto tokens = strutil::split(cmd);
    if (tokens.size() < 2) {
        feedback_ = "输入格式：b <序号> [数量|max] 或 s <序号> [数量|max]";
        return;
    }
    bool isBuy = tokens[0] == "b";
    bool isSell = tokens[0] == "s";
    if (!isBuy && !isSell) {
        feedback_ = "未知命令：" + tokens[0];
        return;
    }
    int idx = -1;
    try {
        idx = std::stoi(tokens[1]);
    } catch (...) {
        feedback_ = "序号要是数字";
        return;
    }
    auto listings = c->market->listAt(c->locationId);
    if (idx < 1 || idx > static_cast<int>(listings.size())) {
        feedback_ = "没有这个序号";
        return;
    }
    const Market::Listing& li = listings[static_cast<std::size_t>(idx - 1)];
    const std::string& goodsId = li.goods->id;

    int qty = 1;
    if (tokens.size() >= 3) {
        if (tokens[2] == "max") {
            if (isBuy) {
                int affordable = li.buyPrice > 0 ? c->player->wallet().get() / li.buyPrice : 0;
                int fit = c->player->inventory().freeSlots() / li.goods->slots;
                qty = std::min({li.quotaLeft, affordable, fit});
            } else {
                const Inventory::Item* item = c->player->inventory().find(goodsId);
                qty = item ? item->qty : 0;
            }
        } else {
            try {
                qty = std::stoi(tokens[2]);
            } catch (...) {
                feedback_ = "数量要是数字或 max";
                return;
            }
        }
    }
    TradeResult r = isBuy ? c->trade->buy(*c, goodsId, qty) : c->trade->sell(*c, goodsId, qty);
    feedback_ = r.msg;
}

#include "util/StringUtils.h"

namespace strutil {

std::size_t displayWidth(const std::string& s) {
    std::size_t w = 0;
    for (std::size_t i = 0; i < s.size();) {
        unsigned char b = static_cast<unsigned char>(s[i]);
        if (b < 0x80) { w += 1; i += 1; }
        else if ((b >> 5) == 0x6) { w += 2; i += 2; }       // 2 字节
        else if ((b >> 4) == 0xE) { w += 2; i += 3; }       // 3 字节（常用汉字）
        else if ((b >> 3) == 0x1E) { w += 2; i += 4; }      // 4 字节
        else { w += 1; i += 1; }
    }
    return w;
}

std::string padRight(const std::string& s, std::size_t width) {
    std::size_t w = displayWidth(s);
    if (w >= width) return s;
    return s + std::string(width - w, ' ');
}

std::vector<std::string> split(const std::string& s) {
    std::vector<std::string> out;
    std::size_t i = 0;
    while (i < s.size()) {
        while (i < s.size() && std::isspace(static_cast<unsigned char>(s[i]))) ++i;
        std::size_t j = i;
        while (j < s.size() && !std::isspace(static_cast<unsigned char>(s[j]))) ++j;
        if (j > i) out.push_back(s.substr(i, j - i));
        i = j;
    }
    return out;
}

std::string trim(const std::string& s) {
    std::size_t b = 0, e = s.size();
    while (b < e && std::isspace(static_cast<unsigned char>(s[b]))) ++b;
    while (e > b && std::isspace(static_cast<unsigned char>(s[e - 1]))) --e;
    return s.substr(b, e - b);
}

std::string toLower(std::string s) {
    for (char& c : s) c = static_cast<char>(std::tolower(static_cast<unsigned char>(c)));
    return s;
}

} // namespace strutil
