# 架构说明（报告"总体设计"章节素材）

## 1. 分层与依赖方向

```text
┌────────────────────────── main/ ──────────────────────────┐
│  main_console（交互版）        main_simulate（headless）   │
└──────────────┬────────────────────────────┬───────────────┘
               │                            │
        ┌──────▼──────┐              ┌──────▼────────┐
        │   ui/ 屏幕   │              │ simulate/ Bot │
        │ (IScreen 实现)│              │ (策略+Resolver)│
        └──────┬──────┘              └──────┬────────┘
               │                            │
        ┌──────▼────────────────────────────▼───────┐
        │   core/  Game（主控） · Session（行动管道）  │
        │   GameContext（组合根） · ScreenManager     │
        │   WeekSettlement（模板方法） · EventBus     │
        └──────┬─────────────────────────────────────┘
               │
   ┌───────────┼──────────────┬──────────────────┐
┌──▼─────┐ ┌───▼────┐  ┌──────▼──────┐  ┌────────▼────────┐
│ economy│ │ player │  │ events/story│  │ time · save ·   │
│ Market │ │ Trade  │  │ Scheduler   │  │ util · config   │
│ 价格因子│ │ System │  │ EndingJudge │  │                 │
└────────┘ └────────┘  └─────────────┘  └─────────────────┘
```

**依赖规则**（构筑时定死，评审可查）：
- 各业务系统互不 include，只前向声明；全靠 `GameContext` 相互访问 → 无循环依赖。
- UI 只依赖 `Game` 公共方法与 `IScreen` 接口 → SFML 版可整体替换。
- 模拟器与游戏共用 `Session::runAction`/`WeekSettlement`/`TradeSystem` → **模拟即游戏**。

## 2. 一次行动的完整数据流（垂直切片核心路径）

```text
玩家输入 "b 4 20"（市场屏）
  → MarketScreen::handleInput 解析
  → TradeSystem::buy：地点/限购/现金/容量 四重校验（错误码返回）
  → Wallet::spend / Inventory::add / Market::consumeQuota
  → EventBus::publish(TradeCompleted) → Player 自动记账（Observer）
  → 玩家按 [8] 或行动点耗尽
  → WeekSettlement::run（模板方法）：支出→学业→延迟效果→节点→换周→行情/情报
  → 待弹窗队列：周报屏 → 固定事件屏 → 回到校园屏
```
