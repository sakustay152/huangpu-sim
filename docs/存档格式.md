# 存档格式 v1

文件位置：`saves/slot0.json`（自动档，每周日结算后写入）与 `saves/slot1..3.json`（手动）。
写入方式：先写 `slotN.json.tmp` 再替换（原子写）；读档校验 `version`，坏档返回错误不崩溃。

```json
{
  "version": 1,
  "meta": {
    "location": "club",          // 当前地点 id
    "rumors": ["【室友情报】…"],  // 本周可见情报文本
    "week": 2, "money": 2843     // 槽位列表摘要用（Game 写入）
  },
  "rng": { "state": 123456789 },           // splitmix64 状态：读档后随机序列完全一致
  "player": {
    "wallet": { "money": 2843 },
    "inventory": {
      "capacity": 30,
      "items": [ { "goodsId": "coffee_ticket", "qty": 5, "slotsPer": 1, "avgCost": 11.0 } ]
    },
    "studyScore": 40,
    "ledger": ["买入 coffee_ticket x5 金额 55"]   // 交易流水（上限 200 条）
  },
  "market": {
    "week": 2,
    "trend":   { "dorm": { "used_book": 0.12 }, "…": {} },  // loc → goods → 周趋势
    "noise":   { "used_book": 1.03 },                        // goods → 日噪声乘数
    "shock":   [ { "goods": "umbrella", "mult": 1.8, "days": 2 } ],
    "quota":   { "dorm": { "used_book": 37 } },              // loc → goods → 今日剩余限购
    "pendingRumor": { "goods": "milk_tea", "up": false },    // 对下一周的情报
    "rumorTexts": ["【室友情报】…"]
  },
  "time":   { "week": 2, "actionsLeft": 6, "studiedThisWeek": false },
  "events": {
    "cooldown":  { "borrow": 3 },                            // 事件冷却（周）
    "scheduled": [ { "week": 4, "effect": { "type": "money", "amount": 600 } } ]  // 延迟效果（室友还钱）
  },
  "flags": { "flags": ["goal_set", "evt_done_w1_opening"] },
  "npcs":  { "affinity": { "roommate": 30, "senior": 0, "xuejie": 15 } }
}
```

## 版本与兼容

- `version: 1` 为当前版本；读取时 `version <= 0`（缺号）视为坏档，`> 1` 提示"存档版本过新"。
- 各系统 `fromJson` 全部使用带默认值的字段读取（`ju::getOr`），旧档缺字段不崩溃。
- 引用完整性兜底：地点 id 非法回落 `dorm`；商品/NPC id 非法直接丢弃该条目。
